What is in it

One profile and the experiences that belong to it. Over twenty-five years as entries, each with what was done and, where a role ended, why.

Skills that carry a level and evidence. A claim with no concrete evidence beside it is an error in the model, not a matter of taste.

Values and a vision that say where this is going. Every page names its source, and that source is this repository: a fact is corrected here and nowhere else.

What the company ships, and the words it means exactly. One product, the Mental Model itself, the features that say what someone can do with it, and the concepts it needs to say so — claim, evidence, document — each a page of its own that another can name.

The file behind the figure

The figure is drawn from one file on this site, model.json, and anyone may fetch it. It lists the entities — the identity, the profile, each experience, each skill and each value — and the edges between them, and it carries the commit and the repository named below even when no JavaScript runs.

The profile, the experiences and the skill levels are my own account of my work; the References table under an entry lists what someone else published, which is what that entry rests on.
