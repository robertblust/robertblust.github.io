# blust.ch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `robertblust.github.io` — a profile page for peers at blust.ch, a talks index, and two migrated decks adapted to the transport-bar shape the GuestGraph deck now has.

**Architecture:** One repository, no build step for the site. Every page is a self-contained HTML file that works from `file://`. Playwright is a dev dependency used only by the PDF and share-card exporters, and by the verification harness. Because there is no test framework and the deliverable is rendered pages, **the tests are Playwright DOM assertions in `verify/check.mjs`** — each task adds assertions first, watches them fail, then implements. This matches the rule both existing repos already enforce: verify by rendering, never by reading the diff.

**Tech Stack:** Static HTML/CSS/JS (no framework), Playwright, pdf-lib, GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-08-22-blust-ch-design.md`

## Global Constraints

- Repository name is `robertblust.github.io` — forced by GitHub, cannot change without losing the domain root.
- Palette, verbatim: `--paper:#0f1013` `--paper2:#191b20` `--ink:#f1ede4` `--muted:#9a9384` `--cobalt:#7aa0ff` `--line:#282a30` `--slab:#16181d` `--lcd:#0a0b0e`.
- Typefaces: IBM Plex Sans (body), IBM Plex Mono (microtype). Google Fonts stylesheet is the only permitted external asset.
- Every page works from `file://` and a plain local server, not only the live domain.
- Bilingual by attribute: German is the element's content, English is `data-en`. Site chrome (profile page, talks index) is English only.
- `lang` describes the source: static `lang="de"` on decks, `applyLang()` sets `en` on load.
- Slide numbers are zero-based everywhere the viewer can see them — kicker, counter, and any audio filename say the same number.
- `<em class='cue'>` inside speaker notes is a stage direction, never spoken. Nested markup in attributes uses single quotes. German quotes are typographic `„…“`. Never put an HTML comment inside a start tag.
- No recorded narration in this project.
- Commits happen when the user asks; suggest a message, don't auto-commit.
- Never mention closed-source predecessor projects.

- [ ] **Step 1: Write the failing test**

Create `verify/check.mjs`:

```js
// The deliverable is rendered pages, so the tests are assertions against a rendered DOM.
// Run against a served copy of the repo: python3 -m http.server 8000
import { chromium } from "playwright";

const BASE = process.env.BASE || "http://localhost:8000";

// Extended by later tasks. `lang` is the expected documentElement.lang AFTER JS runs.
const PAGES = [
  { path: "/", title: /Robert Blust/, lang: "en" },
];

const CHECKS = {
  async title(page, spec) {
    const t = await page.title();
    if (!spec.title.test(t)) return `title ${JSON.stringify(t)} does not match ${spec.title}`;
    if (t.length > 65) return `title is ${t.length} chars, over 65`;
    return null;
  },
  async lang(page, spec) {
    const l = await page.evaluate(() => document.documentElement.lang);
    return l === spec.lang ? null : `lang=${l}, expected ${spec.lang}`;
  },
};

const browser = await chromium.launch();
let failures = 0;

for (const spec of PAGES) {
  const page = await browser.newPage();
  const jsErrors = [];
  page.on("pageerror", e => jsErrors.push(String(e)));
  const problems = [];
  try {
    const res = await page.goto(BASE + spec.path, { waitUntil: "networkidle" });
    if (!res || !res.ok()) problems.push(`HTTP ${res ? res.status() : "no response"}`);
    for (const [name, fn] of Object.entries(CHECKS)) {
      if (spec[name] === undefined && name !== "ogTags" && name !== "canonical") continue;
      const problem = await fn(page, spec);
      if (problem) problems.push(`${name}: ${problem}`);
    }
  } catch (e) {
    problems.push(String(e));
  }
  if (jsErrors.length) problems.push("JS errors: " + jsErrors.join(" | "));
  console.log((problems.length ? "✗" : "✓") + " " + spec.path +
    (problems.length ? "\n    " + problems.join("\n    ") : ""));
  failures += problems.length ? 1 : 0;
  await page.close();
}

await browser.close();
console.log(failures ? `\n${failures} page(s) FAILED` : "\nall checks pass");
process.exit(failures ? 1 : 0);
```
