# SEO — plan

*Spec: `docs/superpowers/specs/2026-08-25-seo-design.md`.*

Ordered so the check lands before the fixes it describes, and so each step is verifiable
on its own.

## 1. The check, first

Add `seo` to `CHECKS` in `verify/check.mjs` and set `seo: true` on all six pages in
`PAGES`. Run the suite. **It must fail** — on `/ideas/` for the three missing OG tags, and
on `/privacy/` for the dangling `#website` reference and the 404 logo. A check that passes
the moment it is written has not been shown to check anything.

## 2. Structured data, rebuilt so it resolves

Replace the `Organization` node with `Person`:

```json
{ "@type": "Person", "@id": "https://blust.ch/#person",
  "name": "Robert Blust", "url": "https://blust.ch/",
  "jobTitle": "Software Engineer & Architect",
  "sameAs": ["https://github.com/robertblust",
             "https://www.linkedin.com/in/robertblust/"] }
```

No `logo` — that key is what pointed at the 404, and a `Person` has no logo to serve. Add
the `WebSite` node the privacy page already claims to be part of, and give every page its
own `WebPage` plus, where nested, a `BreadcrumbList`. Each page carries the whole graph it
references; nothing points across pages.

## 3. The head contract, applied to all six pages

`og:locale:alternate` = `de_CH` everywhere, since every page here is bilingual. `/ideas/`
gains `og:site_name`, `og:image:alt`, `og:locale`. Both decks gain `<meta name="author">`,
which `talks/intro/` on both sibling sites already carries and neither deck here does.

## 4. `/ideas/` gets its own card

Add `{ dir: "ideas" }` to `og-recipe.mjs`, point the page's `og:image` at
`https://blust.ch/ideas/og.png`, and set `card: true` on it in `PAGES`. Then `npm run og`.

## 5. Re-render every card

Editing a page's markup marks its card stale by design — the recipe hashes the page, not
the picture. All six pages are touched, so `npm run og` regenerates all four existing
cards plus the new one, and `og.png`/`og.sha` are committed alongside. This is expected
and is not evidence anything about the images changed.

## 6. Verify

`npm run test:og`, `npm run og:check`, then the browser suite against a served copy. The
`seo` check must now pass on all six pages, and `sitemap.xml` must still list all six.
