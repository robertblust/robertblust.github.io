# Essenzielle Komplexität

Eine kurze (10-Minuten-)Präsentation von **Robert Blust** darüber, wie man ein Problem in
seiner *essenziellen Komplexität* beschreibt – der Anspruch bleibt derselbe wie vor 15 Jahren,
aber der Weg dorthin wird mit KI einfacher.

## Ansehen

**Live:** https://robertblust.github.io/essential-complexity/

Ein eigenständiges HTML-Deck (dunkles Theme, zweisprachig DE/EN).

### Steuerung
- **← →** – blättern
- **N** – Sprecher-Notizen ein/aus
- **L** – Sprache umschalten (DE/EN)
- **F** – Vollbild

## Inhalt dieses Repos
- `index.html` – das Präsentations-Deck (self-contained bis auf die Comic-Bilder)
- `comic-1..6.png` – handgezeichnete Journey-Panels als Seitenmotiv
- `presentation-essential-complexity.pdf` – PDF-Fallback (eine 16:9-Seite pro Slide)
- `presentation-essential-complexity.md` – Sprecher-Skript / Aufbau
